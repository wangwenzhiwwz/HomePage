About the project

SUB.WWZ.iM is an online proxy-link converter that turns common proxy URI formats into a Clash.Meta-compatible YAML configuration. Paste one proxy link per line and the tool generates the configuration for copying or downloading.

Supported proxy link formats

The converter documents support for VMess, VLESS, Hysteria2, Trojan, HTTP, SOCKS5 and Shadowsocks (SS) links. Non-standard variations may not always parse correctly.

Generated Clash.Meta configuration

The generated YAML includes basic settings, DNS configuration, proxy groups and routing rules. The documented groups include node selection, automatic selection, direct connection and service-specific groups such as OpenAI, TikTok, YouTube, Microsoft and Apple.

How to use the converter

Open the tool, paste proxy links into the input area with one link per line, review the generated Clash.Meta YAML, then copy the result or download it as a configuration file.

Key features

  • VMess, VLESS, Hysteria2, Trojan, HTTP, SOCKS5 and SS input formats
  • Automatic generation of Clash.Meta YAML
  • Generated proxy groups and routing rules
  • Copy generated configuration to clipboard
  • Download configuration as clash-meta-config.yaml

Safe conversion workflow

  1. Keep the original subscription or node links in a secure place; they may contain access credentials.
  2. Paste only the supported link formats and review the generated YAML before importing it.
  3. Check proxy names, group references, DNS settings and routing rules for your own client.
  4. Validate the generated file in a separate test profile; do not overwrite the only working configuration.
  5. After testing, keep a dated backup so you can restore the previous profile quickly.

Security note: treat subscription URLs, UUIDs and passwords as secrets. Do not share screenshots or generated configuration files publicly without removing credentials.
