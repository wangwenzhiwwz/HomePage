About the project

APP.WWZ.iM is a categorized resource directory for frequently used websites, AI services, software and digital tools. Instead of keeping useful destinations scattered across bookmarks, the directory brings them together in one searchable interface.

Browse by category

Resources are grouped into practical categories including Web, AI, GenAI, Android, Windows, iOS, Mac, VPS, eSIM, Payzone and Other. This makes it easier to move between work, creative, development and everyday tools.

A broad tool collection

The directory includes website and productivity services, AI assistants and creative platforms, mobile and desktop applications, VPS providers, networking resources and other useful destinations.

Search and quick access

Use the page search to locate a resource by name, then open its official website or service directly. The directory acts as a launch point rather than hosting the listed third-party services.

Key features

  • Categorized website and online-tool directory
  • Dedicated sections for AI and generative AI services
  • Android, iOS, Windows and Mac software resources
  • VPS, eSIM, networking and other practical resources
  • Searchable entries with direct links to external services
