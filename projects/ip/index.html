About the project

IP.WWZ.iM (IP Insight) is a browser-based network information dashboard. It combines public IP detection with location and network context, connectivity checks and browser/device details in a compact interface.

Public IP detection

The project documents concurrent requests to multiple IP lookup sources, including ipify, myip.is and icanhazip. A race-style approach displays the first successful response and is designed to improve IPv6 detection.

Location and network context

Available information can include timezone, local time, coordinates, UTC offset, autonomous system number (ASN) and internet service provider (ISP), using the project's documented geolocation data source.

Connectivity and IP risk links

The dashboard checks request latency to Baidu, Google and GitHub and refreshes those checks periodically. It also provides a link to the official Scamalytics report for the detected public IP, plus an OpenStreetMap-based location view.

Browser and device information

The page can display browser engine, operating system and screen resolution. Some fields depend on browser support and the availability of external lookup services.

Key features

  • Public IPv4 and IPv6 detection using multiple sources
  • Geolocation, timezone, coordinates, ASN and ISP context
  • Connectivity latency checks for selected websites
  • Link to an official Scamalytics IP report
  • OpenStreetMap location display
  • Browser, operating system and screen information
