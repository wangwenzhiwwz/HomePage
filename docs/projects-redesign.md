# WWZ.iM Projects 页面改版说明

## 目标与定位
Projects 从简单的文字链接列表升级为个人数字产品作品集。页面需要让访客快速理解每个项目解决什么问题、当前可用状态，以及进入项目详情或在线工具的路径。保留现有 SEO、项目 URL、导航壳层和原有详情内容。

## 信息架构

### Projects 首页
1. **Hero Banner**：独立数字产品定位、主标题、简短介绍、GitHub 入口与项目统计。
2. **项目筛选**：All、Utilities、Network、Directory、Open source。筛选只影响卡片显示，不改变 URL。
3. **项目卡片**：APP、SUB、RMB、IP、VPS、WBoard。卡片包含编号、类别、名称、用途说明、标签与进入箭头。
4. **设计原则说明**：Clarity、Control、Craft，补充项目设计理念。

### 项目详情页
统一结构：
- 面包屑：Home / Projects / 当前项目
- 专属项目 Banner：项目编号/分类、项目名称、用途说明、抽象主题图形
- 主要操作：打开在线项目、源代码（仅在已知有效地址时显示）、返回项目列表
- 原有详情章节：项目介绍、功能说明、使用方法、注意事项、相关指南
- 站点统一页脚与导航

已覆盖的本地详情页：APP、SUB、RMB、IP、VPS。WBoard 当前以 GitHub 源仓库作为入口，保持“源码项目”定位，不虚构线上演示地址。

## 视觉规范
- **总体方向**：Apple 式编辑型作品集，清晰、安静、留白充分；不使用大面积高饱和渐变或复杂装饰。
- **基础色**：沿用 WWZ.iM 全站语义色与主题变量；Banner 使用雾蓝、暖灰、象牙白，正文仍使用全站文本色。
- **项目辨识**：APP 雾蓝；SUB 灰绿；RMB 暖米色；IP 冰蓝；VPS 石墨灰；WBoard 淡紫灰。颜色只用于卡片顶部插画区域，不扩散成全页面底色。
- **形状**：22–30px 圆角、细描边、轻微柔和阴影；按钮胶囊形。
- **排版**：大标题紧凑字距，正文限制行宽；类别标签使用等宽小字。
- **Banner 图形**：由 CSS 绘制半透明球体、轨道和环形层次，避免使用与项目无关的图库图片。卡片使用简洁符号和独立色调，避免伪造产品截图。

## 交互与响应式
- 卡片 hover 轻微上移，箭头产生小幅位移；不使用明显倾斜或强烈缩放。
- 分类筛选通过按钮的 aria-pressed 状态提供可访问反馈。
- 桌面端三列卡片；中等宽度两列；窄屏单列。
- Banner 桌面端采用文案与图形双栏，移动端改为单栏，图形淡化并退至右下角。
- 尊重 prefers-reduced-motion，关闭非必要过渡。
- 深色模式通过系统配色适配，降低 Banner 装饰对比度，保持正文可读性。

## 内容与链接约束
- 保留已有项目名称、在线域名、源代码地址、SEO canonical、结构化数据和原详情内容。
- WBoard 标记为 Source repository，不标记为已部署服务。
- IP 地理位置应描述为近似信息；VPS 数据以已配置监控数据源为准；SUB 使用前应提醒用户校验配置。
- 不把示意图当作真实产品截图，不添加未验证的功能、指标或服务状态。
