# Portfolio: Unlimited Creativity

这是我的个人官方主页，集成了**商业导演、摄影师、网络工程师与自学开发者**的多重身份展示。本项目遵循极致的**轻量化**与**极简主义**设计理念。



## 🚀 项目理念 (Philosophy)
- **Minimalism:** 删繁就简，只保留最核心的视觉逻辑。
- **Lightweight:** 追求极致的加载速度与高效的代码结构。
- **Cross-over:** 探索技术架构（Logic）与视觉叙事（Art）的交汇点。

## 🛠️ 技术栈 (Tech Stack)
- **Frontend:** HTML5, CSS3 (Bootstrap 5 自定义版)
- **Interactions:** Swiper.js (作品集轮播), AOS.js (滚动动画)
- **Typography:** 现代无衬线字体系统
- **Performance:** 纯静态部署，极致响应速度
