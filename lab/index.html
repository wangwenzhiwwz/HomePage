Working principles

01 / PRODUCT FIRST

Lock product identity

Keep the real device geometry, camera arrangement, buttons, logo, materials and colors stable before optimizing atmosphere or style.

02 / TRACEABLE

Record dependencies

List model files, custom nodes, versions, inputs, outputs and parameters. Never assume a model or node is installed.

03 / ACCEPTANCE

Define what “works” means

Evaluate visual consistency, temporal stability, resolution, artifacts and practical production usability.

04 / RECOVERY

Keep a rollback path

Preserve known-good workflows and document how to revert when a model update or dependency change breaks a result.

A practical image-to-video production path

Use this as a repeatable sequence for product advertising. It is a process template, not a claim that every model or custom node is already installed on the workstation.

STAGE 01 · SOURCE

Prepare a product reference set

Collect clean front, rear, side and detail views under neutral lighting. Keep one approved reference set and note any model-specific visual features that must not change.

STAGE 02 · SHOT DESIGN

Define one camera move

Write down shot duration, framing, camera direction, subject position and background action. Avoid asking the model to redesign the product and move the camera at the same time.

STAGE 03 · LOW-COST TEST

Validate a short sample

Start with a short, lower-resolution test. Change one variable at a time and record the seed, prompt, model, node versions and settings that produced the result.

STAGE 04 · REVIEW

Inspect identity frame by frame

Check silhouette, lens layout, buttons, ports, logo, material, color and scale. Reject clips where the product changes shape even if the overall image looks attractive.

STAGE 05 · FINISH

Enhance only stable footage

After motion and product identity pass review, test enhancement or upscaling on a short segment before processing the full clip.

STAGE 06 · ARCHIVE

Keep a reproducible record

Save the workflow JSON, model file names, custom-node commit/version, input references, output sample, known issues and rollback instructions together.

Delivery acceptance checklist

  • Product body shape and proportions remain stable throughout the clip.
  • Camera modules, buttons, ports, logo and distinctive details match the reference.
  • No obvious flicker, texture crawling, duplicated parts or frame-to-frame warping.
  • Camera movement follows the shot plan and does not obscure key selling points.
  • Output resolution, frame rate, duration and aspect ratio match the delivery brief.
  • Model dependencies, settings and source assets are recorded for later reproduction.

Priority order: product identity → temporal stability → shot communication → image quality → stylistic polish.
