3. 产品图生视频的工作流方向

产品商业视频优先从真实产品图片出发，再设计镜头和环境变化。与完全依赖文本生成相比，图生视频更适合把真实产品外观作为视觉依据，但仍需要逐帧检查生成过程中的结构漂移。

  1. 输入：选择清晰、角度明确的产品原图，确认机身比例、镜头、按键、Logo 与颜色。
  2. 镜头：先定义主体位置、运动方向、景别和背景变化，避免一次要求过多动作。
  3. 生成：先做短片段测试，确认主体稳定后再增加时长和画面复杂度。
  4. 检查：逐帧观察机身变形、镜头数量变化、Logo 错字、材质闪烁与边缘抖动。
  5. 增强：只有在基础画面可用后，再考虑 SeedVR2 等视频增强环节。

以上是工作流设计原则，不是已经验证通过的 ComfyUI JSON 工作流或一键参数预设。

4. 产品一致性验收标准

  • 机身轮廓、长宽比例和厚度在镜头前后保持一致。
  • 摄像头、热成像模块、按键、接口和扬声器的位置与数量正确。
  • 品牌 Logo、屏幕文字和产品型号不出现错误字符或随机变化。
  • 机身颜色、材质、反光和纹理不发生明显跳变。
  • 运动过程中边缘不融化、不拉伸，产品不凭空增加或缺少部件。
  • 同一镜头相邻帧之间保持合理连续，不出现明显闪烁。

验收顺序应先检查产品是否正确，再检查镜头是否自然，最后才评价风格、氛围和特效。

5. 后续补全计划

后续每个可复现工作流都应记录：ComfyUI 版本、节点名称与版本、模型文件及来源、模型放置目录、输入规格、关键参数、显存峰值、输出规格、运行耗时、失败信息和回滚方式。

在这些信息实际验证之前，不提供未经测试的安装命令，也不把模型依赖写成默认已安装。
