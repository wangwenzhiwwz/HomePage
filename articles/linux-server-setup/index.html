⚙️ 服务器初始化与部署指南

基础环境配置、常用工具安装、Xray 面板与 Debian / Ubuntu 系统运维清单。

一、基础环境初始化

在全新的系统（如 Debian）安装 curl、wget，首先需要更新软件包索引并安装基础工具。

apt update
apt install sudo -y
sudo apt update
sudo apt install curl -y
sudo apt install wget -y
sudo apt install unzip -y
已复制！

二、综合工具箱

使用一键脚本，可以快速进行系统优化、Docker 环境就绪以及常用服务部署测试。

bash <(curl -sL kejilion.sh)
已复制！

三、Xray 面板安装 (3x-ui)

安装功能强大的 3x-ui 面板，用于可视化管理多用户节点与配置。

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
已复制！

四、系统快捷配置

快捷修改 root 用户密码，适用于自动化与临时配置场景：

echo root:passwprd123 | chpasswd root
已复制！

五、升级 Ubuntu 版本

此命令将更新软件包列表并将所有已安装的软件包升级到最新版本。建议在跨版本升级之前运行此命令，以确保关键库与依赖处于一致状态。

重要提示： 跨大版本升级前请务必对核心数据、Compose 卷进行独立快照与异地备份。 
sudo do-release-upgrade
已复制！

此命令将检查是否有新的 Ubuntu LTS 版本，并逐步引导完成升级流程。
