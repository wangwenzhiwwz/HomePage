⚙️ 3X-UI 安装与 TLS 升级指南

多协议支持、流量统计、面板可视化管理。

1. 前言

3X-UI 是基于 Xray 核心的多用户图形化管理面板，是目前功能最全、更新最活跃的 X-UI 分支。它支持 REALITY、VLESS、Hysteria2 等多种主流协议，并自带可视化统计与证书管理。

二、3X-UI 一键安装脚本

使用以下命令安装最新稳定版：

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
已复制！

如需安装特定版本（如 v2.2.8）：

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh) v2.2.8
已复制！

三、面板常用管理命令

x-ui              # 管理菜单 (更多功能)
x-ui start        # 启动面板
x-ui stop         # 停止面板
x-ui restart      # 重启面板
x-ui status       # 查看状态
x-ui enable       # 设置开机自启
已复制！

四、TLS 证书申请与配置

在开启 TLS 之前，建议先安装 acme.sh 并申请证书：

# 申请证书
~/.acme.sh/acme.sh --issue -d 你的域名 --standalone

# 安装证书到 root 目录
~/.acme.sh/acme.sh --installcert -d 你的域名 --key-file /root/private.key --fullchain-file /root/cert.crt
已复制！

申请完成后，在面板节点配置中填入路径：/root/cert.crt 和 /root/private.key。

五、常见问题排查

默认凭据： 初始用户名和密码均为 admin，请安装后立即修改。

无法访问面板？ 请确保服务器防火墙已放行面板端口（默认 54321）：

iptables -I INPUT -p tcp --dport 54321 -j ACCEPT
已复制！
