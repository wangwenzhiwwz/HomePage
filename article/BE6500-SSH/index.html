安装 ShellCrash 科学上网

小米路由器 BE6500 解锁 SSH 并安装 ShellCrash，无需刷入 OpenWrt，同时保留路由器原有功能。BE3600 与 AX3000T 也可参考。

2025-11-12约 1 分钟Wang Wenzhi

开始之前

请先备份路由器配置。 以下操作需要管理员权限，执行命令前请确认路由器型号、固件版本和后台地址与教程一致。

先登录路由器后台并在地址栏中找到当前会话的 stok 值。下面命令中的 xxx 需要替换为你的实际值。

一、BE6500 解锁 SSH

1. 以管理员身份运行命令提示符

在 Windows 搜索 CMD，右键选择“以管理员身份运行”，依次执行：

curl -X POST http://192.168.31.1/cgi-bin/luci/;stok=xxx/api/xqsystem/start_binding -d "uid=1234&key=1234'%0Anvram%20commit'"

curl -X POST http://192.168.31.1/cgi-bin/luci/;stok=xxx/api/xqsystem/start_binding -d "uid=1234&key=1234'%0Ased%20-i%20's%2Fchannel%3D.*%2Fchannel%3D%22debug%22%2Fg'%20%2Fetc%2Finit.d%2Fdropbear'"

curl -X POST http://192.168.31.1/cgi-bin/luci/;stok=xxx/api/xqsystem/start_binding -d "uid=1234&key=1234'%0A%2Fetc%2Finit.d%2Fdropbear%20start'"

2. 登录路由器并修改密码

使用 PuTTY 或其他 SSH 工具连接 192.168.31.1，用户名为 root。初始密码可通过小米路由器 SSH 密码计算工具获得。

echo -e 'admin\nadmin' | passwd root

示例命令会把 root 密码改为 admin。正式使用时应替换成强密码，并妥善保存。

二、安装 ShellCrash

SSH 登录路由器后，可使用 ShellCrash 官方路由器安装方式：

export url='https://testingcf.jsdelivr.net/gh/juewuy/ShellCrash@dev' \
  && sh -c "$(curl -kfsSl $url/install_en.sh)" \
  && . /etc/profile > /dev/null

安装完成后输入 crash 打开交互式管理菜单，按提示选择内核、导入订阅并配置启动方式。

crash        # 打开管理菜单
crash -h     # 查看命令帮助

Web 管理界面默认可尝试访问 http://192.168.31.1:9999/ui/。如页面未更新，可使用 Ctrl + F5 强制刷新。
